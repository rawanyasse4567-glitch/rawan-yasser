MyPortfolio - Setup and Editing

Project structure:
- Assets/: images, hero background, and resume file (cv.pdf)
- Css/style.css: website colors, layout, and responsive styles
- Js/script.js: menu interactions and active navigation
- index.html: main page content

Run the website:
1. Extract the ZIP file.
2. Open the MyPortfolio folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.

Customize:
- Add your photo as Assets/images/profile.jpg. The photo is displayed in a circular frame with cropping to keep it inside the frame.
- Replace Assets/images/hero-bg.svg to change the hero background.
- Edit text, email, project descriptions, and skill levels in index.html.
- Change colors and layout in Css/style.css.
- Add your resume as Assets/cv.pdf.


HOW TO ADD YOUR PROFILE PHOTO
1. Open the Assets/images folder.
2. Copy your photo into that folder and name it profile.jpg.
3. Open index.html in your browser. The photo will appear automatically.
The photo is shown inside a circular frame and cropped to fit. Use JPG format and keep the exact filename profile.jpg. In Visual Studio Code, the photo line is in index.html and starts with <img class="profile-photo" src="Assets/images/profile.jpg" ...>.
